1. Prompt Engineering
Pengertian Prompt
Prompt adalah instruksi, pertanyaan, atau masukan yang diberikan pengguna kepada AI (Artificial Intelligence) untuk menghasilkan respons atau output tertentu. Prompt dapat berbentuk pertanyaan sederhana, perintah, deskripsi, hingga instruksi yang lebih kompleks.
Dalam penggunaan AI, kualitas prompt sangat memengaruhi hasil yang diberikan oleh model. Semakin jelas dan spesifik instruksi yang diberikan, semakin besar kemungkinan AI menghasilkan jawaban yang sesuai dengan kebutuhan pengguna.

Jenis pendekatan prompt
Terdapat dua pendekatan dasar dalam memberikan instruksi kepada AI:
1. Without Context
Prompt diberikan tanpa informasi atau latar belakang tambahan. AI hanya mengandalkan instruksi yang tersedia sehingga hasilnya cenderung bersifat umum.
2. With Context
Prompt diberikan dengan informasi pendukung atau latar belakang yang relevan. Dengan adanya konteks, AI dapat memahami kebutuhan pengguna secara lebih spesifik dan menghasilkan respons yang lebih sesuai.

Contoh sederhana:
Without Context: "Buatkan deskripsi tentang teknologi."
With Context: "Buatkan deskripsi tentang perkembangan teknologi digital untuk mahasiswa semester pertama dengan bahasa sederhana dan maksimal 150 kata."
Good Prompt Structure
Untuk menghasilkan prompt yang efektif, terdapat empat komponen utama yang dapat digunakan:

Role = Menentukan peran atau posisi AI, misalnya sebagai guru, programmer, atau desainer.
Task = Menjelaskan tugas atau pekerjaan yang harus dilakukan AI.
Context = Memberikan informasi tambahan sebagai latar belakang agar AI memahami kebutuhan pengguna.
Format = Menentukan bentuk hasil yang diinginkan, seperti paragraf, tabel, poin-poin, atau kode program.

Contoh penerapan:
Role: Kamu adalah seorang desainer grafis profesional.
Task: Buatkan konsep desain poster kegiatan kampus.
Context: Poster ditujukan untuk mahasiswa baru dengan tema teknologi digital.
Format: Sajikan dalam bentuk tiga konsep desain beserta penjelasan singkat.

Keuntungan Prompt Engineering
Prompt Engineering memiliki beberapa manfaat dalam penggunaan teknologi AI, di antaranya:
1. Meningkatkan performa AI Model
Membantu AI menghasilkan jawaban yang lebih relevan, akurat, dan sesuai dengan instruksi yang diberikan.
2. Mengurangi Bias dan Respons yang Offensive
Instruksi yang disusun dengan baik dapat membantu mengarahkan AI agar memberikan respons yang lebih objektif, sopan, dan sesuai konteks. Namun, hal ini tidak sepenuhnya menghilangkan bias.
3. Meningkatkan Kontrol dan Predictability
Pengguna dapat mengatur arah, gaya bahasa, tingkat detail, serta format jawaban sehingga hasil AI lebih mudah diprediksi.
4. Memberikan Pengalaman Pengguna yang Lebih Baik
Prompt yang jelas dapat mengurangi kesalahpahaman antara pengguna dan AI, sehingga proses mendapatkan informasi menjadi lebih efektif.



2. Git & GitHub
Pengertian Git
Git adalah Version Control System (VCS) atau sistem pengontrol versi yang digunakan untuk mencatat, melacak, dan mengelola perubahan pada file dalam sebuah proyek.
Git memungkinkan pengguna mengetahui siapa yang melakukan perubahan, kapan perubahan dilakukan, serta bagian apa saja yang mengalami perubahan. Dengan begitu, pengguna dapat melihat riwayat perkembangan proyek dan kembali ke versi sebelumnya apabila diperlukan.

Git diciptakan oleh Linus Torvalds pada tahun 2005. Awalnya, Git dikembangkan untuk membantu proses pengembangan kernel Linux. Git dirancang agar proses pengelolaan kode menjadi lebih cepat, efisien, dan dapat dilakukan secara terdistribusi oleh banyak pengembang.
Perbedaan Git dan GitHub
Meskipun sering digunakan bersamaan, Git dan GitHub memiliki fungsi yang berbeda.
Git: Perangkat lunak untuk mengelola dan melacak perubahan pada proyek secara lokal.
GitHub: Platform berbasis web yang menggunakan Git untuk menyimpan repository secara online, berbagi proyek, dan berkolaborasi dengan pengguna lain.

Dengan kata lain, Git berfungsi untuk mengelola versi proyek, sedangkan GitHub menjadi tempat untuk menyimpan dan mengembangkan proyek bersama secara online.
Git Workflow
Git memiliki tiga bagian utama dalam alur kerjanya (Git Workflow), yaitu:

Alur kerja Git :
1. Working Directory
Tempat pengguna membuat dan mengedit file proyek.
2. Staging Area
Tempat menyiapkan perubahan yang akan dimasukkan ke commit berikutnya.
3. Git Directory (Repository)
Tempat Git menyimpan riwayat perubahan dan data proyek yang sudah di-commit.

Working Directory
Merupakan direktori atau folder proyek tempat pengguna melakukan aktivitas seperti membuat, mengedit, dan menghapus file. Perubahan yang dilakukan di bagian ini belum otomatis disimpan sebagai riwayat Git.
Staging Area
Merupakan area persiapan untuk menentukan perubahan file mana saja yang akan dimasukkan ke dalam commit berikutnya. Pengguna dapat memilih perubahan tertentu sebelum menyimpannya ke dalam riwayat Git.
Git Directory (Repository)
Merupakan tempat Git menyimpan seluruh informasi penting mengenai proyek, termasuk metadata, objek database, dan riwayat commit. Bagian ini memungkinkan pengguna melihat serta mengelola versi proyek sebelumnya.

Dasar Penggunaan Git melalui Command Prompt (CMD)
Untuk menggunakan Git melalui Command Prompt atau terminal, pengguna perlu memastikan Git sudah terinstal pada perangkat.
